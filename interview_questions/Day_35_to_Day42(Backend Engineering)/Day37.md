1. What is PostgreSQL?
A. PostgreSQL is an open-source relational database management system that stores structured data in tables and supports SQL, constraints, relationships, transactions, indexing, concurrency, and durable persistent storage.

2. Primary key vs Foreign key
A. A primary key uniquely identifies a row in its own table. A foreign key references a key in another table and enforces a relationship between those tables.

3. Why transactions?
A. Transactions allow multiple database operations to be treated as one logical unit of work. They can be committed when all operations succeed or rolled back when something fails, helping maintain data consistency.

4. Why parameterized queries?
A. Parameterized queries keep SQL syntax separate from user-supplied values, preventing user input from being interpreted as SQL code and significantly reducing SQL-injection risk.
