1. What is LangGraph?
A. LangGraph is a low-level orchestration framework for building stateful LLM workflows and agents as graphs of nodes and edges. It allows developers to manage shared state, branching, loops, persistence, deterministic logic, and model-driven steps with explicit control over workflow execution.

2. Why LangGraph Instead of a Chain?
A. I use a simple chain when the workflow is linear and deterministic. I use LangGraph when the application needs shared state, conditional routing, loops, persistence, human approval, or more complex orchestration.
